# Projet Brume

Jeu Android de magie ultra-réaliste.

**Démarré le:** 15/09/2026
**Statut:** Développement en cours

---

## 📱 Niveaux Graphiques
- **Faible:** 720p (pour mobiles bas de gamme)
- **Moyen:** 1080p (Galaxy Tab A9+ / S25 Ultra)
- **Ultra:** 1440p/4K (S25 Ultra avec NPU)

- Sons immersifs (environnement, sorts, combats)
- Runes d'invocation
- Effets spéciaux ultra-réalistes
